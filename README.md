# A-Travel-Itinerary-Design-and-Optimization-Application-Based-on-Real-Time-Data

## Setup
1. Clone: `git clone https://github.com/iambis/A-Travel-Itinerary-Design-and-Optimization-Application-Based-on-Real-Time-Data`
2. Install: `cd backend && npm install`, `cd frontend && npm install`
3. Setup .env: Copy `.env.example` to `.env` and fill in API keys.
4. Run: `cd backend && npm start`, `cd frontend && npm start`

## Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express, SQL (Sequelize)
- Chatbot: Dialogflow
- Realtime: Firebase
- Deployment: Vercel, Heroku
